# Product

## Register

brand

## Users

Bootcamp participants (U-INSPIRE 101 — DRR practitioners, students, early-career professionals) and the session presenter. The deck needs to teach: how to use freebuff + opencode with Agent Skills + MCP to build a deployable, interactive DRR portfolio — not just static AI-generated infographics.

## Product Purpose

A 13-slide presentation deck for SESI-5 of the "Decode Risk. Ship Impact." bootcamp. It walks from the problem (InaRISK is slow and clunky; you only need one kecamatan with a nice coat) through the stack, PRD workflow, Skills & MCP concepts, to a live interactive prototype (Kampung Melayu flood dashboard) and the deploy checklist. The deck itself embodies the "interactive beats infographic" thesis.

## Brand Personality

civic · grounded · direct

Like a laminated flood contingency map pinned to a warung wall in Kampung Melayu: practical, trusted, annotated, public-information clear. Not flashy, not dark-ops-room, not editorial-magazine. The authority comes from the information, not the production value.

## Anti-references

- InaRISK (slow, clunky, forces zooming, too many layers for one kecamatan)
- AI-generated infographics (static, one-way, reads as fake)
- Dark "ops-room" dashboards (generic techy, not civic)
- The editorial-typographic lane (serif italic + drop caps, not this brand)
- Side-stripe bordered cards, hazard-stripe patterns, numbered section eyebrows

## Design Principles

1. **Small, evidence-based, usable, honest** — the bootcamp's own bar; the deck should demonstrate it.
2. **Civic first, not techy** — the case is a real place (Kampung Melayu) and a real frustration (InaRISK). The tools serve the case, not the other way around.
3. **Show, don't tell** — the interactive prototype is embedded in the deck; the deck itself is a working prototype.
4. **Every source carries a trail** — sample data is clearly labeled; official data is referenced, not faked.
5. **One kecamatan, one journey** — focus over breadth. The deck proves the concept with one case, not a platform.

## Accessibility & Inclusion

- WCAG AA (body text ≥4.5:1, large text ≥3:1)
- prefers-reduced-motion respected
- English text, legible font sizes in presentation context
- Slides work in a browser (no build tooling needed)
