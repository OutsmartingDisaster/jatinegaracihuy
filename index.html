Write the PRD first.

Discipline before code. The PRD is the contract between you and your coding agent.

1

Shared understanding — user + decision agreed upfront.

2

Scope control — non-goals stop the agent from inventing features.

3

Measurable done — expected states, not "looks nice".

✗

Without it — agent guesses, scope creeps, output is hard to audit.

Anatomy of a PRD — everything from stack to pixels:

userpurposepages / flow tech stackDB schemaAPIUI / UX constraintsseed dataexpected statesnon-goals

freebuff — turn the case into a PRD.

Input: case brief + constraints. Output: PRD.md with scope, non-goals, and Pass 01–04.

Create a PRD for a flood-history dashboard for Kampung Melayu, Jatinegara. User: a resident asking "is my area at risk, and what happened last time?" Data: sample only — no live TMA, no official warning. Stack: Next.js, TypeScript, Tailwind, Turso. Include: user, purpose, pages/flow, tech stack, DB schema, API, UI/UX, seed data, expected states, non-goals, and Pass 01–04.
expected output
PRD.md

Scope limited to one kelurahan. Non-goals stated. No live-warning features invented.

verify before coding

Open PRD.md, read the non-goals, confirm the passes. Then hand it to opencode.

opencode — build one pass, stop, report.

Pass 01 prompt Read PRD.md. Build Pass 01 only: - Next.js app shell + navigation - visible disclaimer - Turso schema + seed script Do NOT build event interaction or deployment. Stop. List changed files. How to run + seed. Report.
Pass 02 prompt Pass 01 is verified. Build Pass 02 only: - event selector - read events from Turso - show details + risk verdict - empty state No live data. No auth. Stop. List changed files. How to test the journey. Report.

Rule: one pass per prompt. Ask it to stop and report. Verify locally, then continue.

Deploy — pick your path.

Vercel · recommended
  • Easiest for Next.js
  • Connect the GitHub repo
  • Add TURSO_* env vars
  • Deploys automatically on push
Cloudflare
  • Good for DNS / domain control
  • Cloudflare Pages for the app
  • May need a Next.js adapter
  • Use if you already host DNS here

Do

  • Give one pass at a time
  • Ask it to stop after each pass
  • Ask for changed files
  • Verify locally before continuing
  • Keep data sample-based

Don't

  • Ask for the full app in one prompt
  • Claim official live warnings
  • Scrape restricted data
  • Add auth/admin unless needed
  • Let the agent invent features

What is a Skill?

Definition

A skill is a packaged workflow + knowledge an agent loads on demand.

  • Not a plugin — nothing injected every run
  • Loaded only when the task matches

Recipe card

You don't read every card in the box — you pull the one whose title matches the dish. The agent reads SKILL.md and follows the workflow.

Skills map to the DRR pipeline

research

quick-research, websearch — build the evidence trail.

build

visual

generate-image — maps & assets.

evidence

data skills — structure the source trail.

What is MCP?

Model Context Protocol — an open standard for agents to connect to external tools & data.

MCP servers = live reach

  • Expose tools & data to the agent
  • Called like built-in tools, while it codes

Skills in practice — impeccable.

Say "pake skill impeccable" and the agent loads the workflow — rules that keep your Jatinegara dashboard from looking like AI slop.

What the skill enforces

  • No reflex-reject fonts (Syne, Inter, Space Grotesk…)
  • No side-stripes, gradient text, or striped backgrounds
  • No numbered eyebrows above every section
  • OKLCH colors, WCAG contrast, real hierarchy
for the Jatinegara case
Civic, not generic

A public-information look — like a flood map on a warung wall. Distinctive, readable, honest.

You: "pakai skill impeccable untuk review dashboard Kampung Melayu"
Agent: loads SKILL.md → checks palette, typography, spacing, contrast → fixes and reports changes.

MCP in practice — QGIS + GEE.

MCP servers give the agent live access to GIS and satellite tools — so analysis happens inside the conversation, not by hand.

QGIS MCP · spatial analysis
  • Load InaRISK hazard layer → clip to Jatinegara
  • Intersect with kelurahan boundaries → Kampung Melayu
  • Compute flooded area per kelurahan
  • Export GeoJSON for the web app
GEE MCP · satellite analysis
  • Sentinel-1 SAR flood detection (before/after)
  • DEM elevation → slope risk for the case
  • Compare 2013, 2020, 2021 flood extents
  • Export GeoTIFF / CSV for evidence

Prompt: "Pakai GEE MCP. Deteksi genangan Jan 2020 di Jatinegara, clip ke Kampung Melayu, hitung luas, export GeoJSON."

QGIS & GEE MCP must be installed & configured first — like Turso or GitHub MCP.
