Don't Download Everything.

Use STAC — SpatioTemporal Asset Catalog.

What STAC does

Provides a standard structure for finding and describing geospatial assets by spatial + temporal metadata. STAC API enables programmatic dataset search.

STAC SEARCH WORKFLOW QUESTION ↓ AOI (area of interest) ↓ DATE RANGE ↓ STAC SEARCH ↓ AVAILABLE IMAGERY ↓ PROCESS ↓ RESULT

Disaster Research Skill

The skill must constrain the agent — prevent hallucination and bad practice.

NEVER
  • Invent disaster statistics
  • Invent coordinates
  • Mix incompatible datasets
  • Hide uncertainty
  • Treat model output as observation
ALWAYS
  • Cite source
  • Preserve provenance
  • Record date, CRS, resolution
  • Record temporal coverage
  • Identify assumptions
  • Validate results

PART 09

Git + CI/CD

Version control, provenance, automated validation.

Git From Day One

# start the repo git init git add . git commit -m "initial project" # then for every change feature ↓ test ↓ commit ↓ push
why
  • Track every decision
  • Rollback mistakes
  • Evidence trail for the project
  • Collaboration with team

DRR Data Provenance

Git isn't just for code. Track your data lineage.

data/ ├── raw/ ├── processed/ ├── derived/ ├── metadata/ └── provenance/
every dataset needs
  • source — where it came from
  • date — when collected
  • license — usage rights
  • method — how processed
  • CRS — coordinate system
  • resolution — spatial detail
  • version — iteration number

CI/CD Pipeline

git push │ ▼ GitHub │ ▼ CI ├── lint ├── test ├── typecheck ├── build └── data validation │ ▼ Cloudflare │ ▼ PRODUCTION

Cloudflare provides Workers Builds for Git integration + GitHub Actions for custom pipelines.

Disaster Data CI

This is what makes DRR projects different from regular web apps.

data CI checks
  • GeoJSON valid
  • CRS correct
  • Geometry valid
  • No duplicate IDs
  • Required fields exist
  • Dates valid
  • Coordinates within AOI
  • Dataset metadata exists
  • Source URL exists
why this matters

A broken GeoJSON silently produces a wrong map. CI catches it before anyone sees it.

regular web CI

lint · test · build

DRR web CI

lint · test · build + data validation + spatial checks
